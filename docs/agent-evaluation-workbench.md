## 边界
此脚本测 Agent 主循环，不测实际微信投递、扫码登录或跨批次消息顺序。现有测试覆盖工具错误、轮次耗尽、虚构时间拒绝、熔断探测、连接池以及批次内同用户串行和不同用户并行。
不要将批次内串行表述成跨所有账号/进程的同用户全局顺序保证。
当前时间校验只检查时间字符及内部标记，并不能保证课程名、教师、教室完全来自工具。真实评测发现此类错误时，应扩大事实验证或回退到确定性表达。

## 后端更新后的 Agent 行为

- 会话记录附带实际课表快照版本；同步、恢复、课程编辑或单周调课后，不再向模型提供旧版本的助手回答，保留用户追问并要求重新查询。
- 唯一有效学校课表优先；仍有歧义时展示候选编号。用户可发送“使用课表 123”，后端检查所属用户后在当前渠道保存选择 24 小时。选择依赖 Agent Redis；保存失败时不会宣称成功。
- 新增只读工具 get_schedule_status，查询课表、学校绑定、最近同步与最新任务状态，不发起同步。
- get_weather 增加 daily 全天天气与温度，rain 仍表示所选时段降雨；晨报和聊天采用统一降雨概率阈值。
- AGENT_TURN_TIMEOUT_SECONDS 默认 25 秒，供本轮主模型、意图提取、润色和模型队列等待共同使用。天气请求也按剩余预算收缩或跳过；数据库查询和渠道投递不受此预算硬中断。
- 课程结论需要本轮工具依据，空结果和工具错误分别处理；周课表允许长回复，模型截断则回退完整模板，润色不得丢失模板中已列出的课程名称和时间。

整改回归测试：tests/test_agent_backend_alignment.py。真实模型表达与跨渠道投递仍需独立联调。


## 聊天同步与完成通知

- 明确的“同步课表”指令只提交后台任务，活动任务复用，30 秒内重复请求复用最近任务。
- 微信 ClawBot 请求把原渠道、账号、收件人和消息 ID 与同步任务一起保存。
- 结果通知等待初始回复投递成功（channel_messages.status=done）及同步进入 succeeded/failed；后台自动重试期间不发送失败通知。
- 独立通知线程轮询持久化订阅，重启可继续；通知行按租约领取，使用固定 client_id，投递失败最多尝试 3 次，间隔 30 秒。
- 投递前重新核验原账号与用户绑定，使用当前 context_token。解绑、账号失效或消息上下文不可用时停止通知；投递失败不改变课表同步结果。
- 网络超时或发送后进程崩溃可能产生不确定投递；固定 client_id 用于渠道去重，但不能据此声称严格恰好一次。
- 学校登录失效指管理员教务连接失效，通知引导管理员重新连接；其他原因包括超时、服务不可用、学期未发布、绑定变更、数据异常和系统异常。通知不直接输出原始异常内容。
- 企业微信当前使用一次性 response_url，未接入第二条主动通知；其初始回复不承诺通知，用户可查询同步进度。
- 升级包含迁移 0019_sync_notifications；应用启动也会幂等补齐通知表和 error_code 列。

回归：tests/test_agent_sync.py、tests/test_academic_sync_notifications.py；队列、通知顺序、租约恢复和身份变更的真实 PostgreSQL 测试位于 tests/test_academic_jobs.py，需设置 TEST_ACADEMIC_QUEUE_DB=1 并使用本地测试数据库。所有渠道投递均应模拟，离线测试不发真实消息。

提交前审查补充：同步指令必须以明确动作开头，历史描述、进度问句与取消指令不提交；组合查询中的“什么”或“完成后”不再误阻断提交。模型的“已提交/已完成”声明必须有本轮对应任务状态支持，等待完成不视为成功声明。


## 同步状态统一与多轮回归

提交回复、进度追问和完成通知采用同一组后端任务状态模板。明确的同步状态问题，以及最近同步对话后的“好了吗”，直接查询当前用户的任务；不调用模型。排队重试与最终失败分别表达，保存阶段不宣称已完成，无任务记录不推断成同步成功。混合课程/天气问题保留原查询流程。

新增 tests/test_agent_sync_multiturn.py，连续经过真实渠道服务入口、Redis 历史处理、工具调用循环和通知处理器；仅模拟数据库、Redis、模型 HTTP 与消息发送。涵盖重复提交、排队追问、更新成功、内容未变化、最终失败、通知后查明天课表、教室追问、截图中的矛盾回答回退及用户隔离。GitHub Agent 离线工作流已纳入此文件及同步、通知、会话失效回归。

这些是离线流程回归，不代表真实模型表达质量或实际微信投递成功率；不发送用户数据、不触发真实学校同步。同步完成后自动执行待办查询仍未在本轮实现。
