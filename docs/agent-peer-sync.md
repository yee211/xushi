# Agent 课表同步对象

- `同步课表`、`同步我的课表`：仅同步当前账号绑定的学校身份。
- `同步张三的课表`、`更新室友课表`：按当前账号已保存同学的姓名、备注或学生 ID 唯一定位，仅同步此人已保存学期。
- `同步全部同学课表`：同步当前账号已保存的全部同学，包含各自已保存学期，不包含自己的课表。
- `同步同学课表`、`同步全部课表`：要求用户重新发送明确对象的完整同步指令。

新增技能 `sync_other_schedule(person)`、`sync_all_other_schedules()` 和 `get_other_schedule_status()`。同步权限来自本轮明确指令，模型不能把单人授权扩大到全部或自己的课表。未保存或同名多人时不提交任务，提示使用唯一备注重新发送。

复用 academic_other_sync_jobs 后台任务，重复的相同范围任务复用已有任务；范围不同时提示等待，避免把部分任务描述成全部同步。提交回复返回 pending 和任务 ID，不承诺完成通知；进度可在小程序查看。学校返回异常时保留原课表。

同学同步后的“同步好了吗”“好了吗”查询本渠道最近同学任务；明确询问“我的同步好了吗”切回自己的任务。按姓名询问同学任务时核验最近任务包含此人，不能借用另一人的进度。自己的完整同步指令始终优先于历史追问。
